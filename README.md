# Knowledge Base

Base de conhecimento interna para estagiários de TI, com artigos sobre problemas comuns do dia a dia (rede, impressora, internet, etc.).

## Objetivo

Centralizar o conhecimento operacional da equipe de TI em um só lugar, permitindo que qualquer pessoa consulte artigos existentes antes de abrir um chamado ou pedir ajuda, e que administradores mantenham esse conteúdo atualizado.

## Funcionalidades

- **Artigos** — criação, edição, consulta e exclusão de artigos em Markdown.
- **Autenticação** — acesso controlado por login.
- **Papéis de usuário (roles)** — administradores gerenciam usuários e conteúdo; demais usuários têm acesso de consulta.

## Estrutura do repositório

```
.
├── backend/    # API e persistência

```
